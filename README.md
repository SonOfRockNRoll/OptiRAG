# OptiRAG: Akıllı Optisyenlik Asistanı
Bu proje, **İSTE Mühendislikte Bilgisayar Uygulamaları II** dersi kapsamında geliştirilmiş bir **Agentic RAG** sistemidir.

### Özellikler:
* **Hafta 7:** Gelişmiş Prompt Engineering ve Sistem Talimatları.
* **Hafta 8:** ChromaDB ile Vektör Veritabanı ve Web Scraping.
* **Hafta 9:** Agentic AI (ReAct döngüsü) ile dinamik araç kullanımı.

### Kurulum:
1. `pip install -r requirements.txt`
2. `python3 setup_db.py`
3. `streamlit run app.py`
